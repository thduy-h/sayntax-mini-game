## API route review

| Route | Auth and ownership | Validation, limits, errors, replay |
|---|---|---|
| `GET /auth/callback` | Exchanges Supabase code, redirects to fixed onboarding or sign-in. | No request body. Invalid/expired code gets generic user-facing message; browser callback/session test absent. |
| `POST /api/asr/transcribe` | Public same-origin endpoint, upstream key/token server-side. | MIME, file-size, timeout, per-instance rate guard; `formData()` parses before actual Blob size check; proxy body experiment 11mb. Upstream errors mapped to fallback. Replays consume ASR. |
| `GET /api/programs` | `getUser`, query filtered by current user. | UUID query validation, generic DB error. |
| `POST /api/programs` | `getUser`, user ID server-set, seed ID pair checked. | Workspace `unknown`; no body/depth cap; upsert on user/step gives last-writer-wins, no version check. |
| `POST /api/program-runs` | `getUser`, user ID server-set, seed pair checked. | Execution result shape checked but client-reported result trusted; unbounded strings/arrays and workspace; upsert then insert are nontransactional; replay duplicates runs. |
| `POST /api/progress` | `getUser`, user ID server-set, seed pair checked. | Small shape; can mark completed via direct API without evaluator; legacy table. Upsert idempotent but status can regress. |
| `POST /api/voice-command-logs` | `getUser`, user ID server-set, seed pair checked. | Transcript min only, parsed action passthrough, no size cap; inserts repeat on replay. |

No evidence of exception text or secret leakage from these API responses. Supabase RLS is the second ownership boundary. Live policy application, grants, auth provider settings, and rate behavior across Vercel instances require staging verification.
