# Title
Extract shared lesson-engine text/block helpers into internal helpers.ts

# Goal
Eliminate the helper duplication between `packages/lesson-engine/src/index.ts`
and `packages/lesson-engine/src/evaluate-runtime.ts` by moving five pure
helpers into a new internal module. No behavior change — this is a pure
refactor to remove duplicate source.

The helpers to extract are (copy them VERBATIM from `index.ts` — character-
identical — so semantics cannot drift):

1. `normalizeText(value: string): string`
2. `comparableValue(value: string | number | boolean): string | number | boolean`
3. `validatePrintText(output: string[], text: string): boolean`
4. `flattenBlocks(blocks: WorkspaceBlock[]): WorkspaceBlock[]`
5. `findVariableBlock(blocks: WorkspaceBlock[], expectedName: string)`

Reference source of truth for verbatim copies: `index.ts` lines ~311–356:

```typescript
function flattenBlocks(blocks: WorkspaceBlock[]): WorkspaceBlock[] {
  return blocks.flatMap((block) => [block, ...flattenBlocks(block.children ?? [])]);
}

function normalizeText(value: string) {
  return value
    .trim()
    .toLowerCase()
    .normalize("NFD")
    .replace(/[\u0300-\u036f]/g, "")
    .replace(/đ/g, "d")
    .replace(/\s+/g, " ");
}

function comparableValue(value: string | number | boolean) {
  if (typeof value === "string") {
    const trimmed = value.trim();
    const num = Number(trimmed);
    if (trimmed !== "" && Number.isFinite(num)) return num;
    return normalizeText(trimmed);
  }
  return value;
}

function findVariableBlock(blocks: WorkspaceBlock[], expectedName: string) {
  const normalizedName = normalizeText(expectedName);
  return blocks.find(
    (block) =>
      block.type === "variable" &&
      typeof block.fields?.name === "string" &&
      normalizeText(block.fields.name) === normalizedName,
  );
}

function validatePrintText(output: string[], text: string) {
  return output.length === 1 && normalizeText(output[0] ?? "") === normalizeText(text);
}
```

These five definitions are ALSO present in `evaluate-runtime.ts` (lines ~8–44
at time of writing). They must be identical after the refactor.
