# User Flows

## Student

1. Sign up or sign in
2. Choose the student role
3. Complete onboarding and accessibility preferences
4. Land on the student dashboard
5. Open a lesson
6. Build a solution with blocks or voice commands
7. Run the program and review feedback
8. Save progress and finish the lesson step
9. Submit a confidence check-in

## Admin

1. Sign in
2. Access the admin dashboard
3. Create or edit lessons and lesson steps
4. Manage role model inspiration entries
5. Review student progress metrics
6. Review voice command logs
