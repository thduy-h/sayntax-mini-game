# Product Spec

## Vision

SAYNTAX helps female students with motor disabilities learn computational thinking through guided block-based lessons, voice input, and encouraging support systems that reduce physical barriers. Its promise is **Công nghệ không rào cản**.

## MVP Scope

- Email/password auth with Supabase
- Student/admin roles
- Accessibility settings and onboarding
- Guided Blockly lessons
- Rule-based Vietnamese voice commands
- Lightweight program simulation
- Progress tracking and confidence check-ins
- Role model inspiration content
- Admin lesson and content management

## Out of Scope for v1

- Scratch project import/export
- Sprite animation or stage rendering
- Costume editor
- Sound editor
- Full game runtime or scripting VM
- LLM-backed voice or tutoring

## Success Criteria

- Students can complete lessons with blocks or voice
- Accessibility settings are persistent and easy to use
- Admins can manage lesson content without editing code
- Progress, confidence, and voice logs are stored for review
