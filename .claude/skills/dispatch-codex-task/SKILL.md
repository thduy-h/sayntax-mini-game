---
name: dispatch-codex-task
description: Turn a planned implementation into a narrow Codex CLI task with file scope, verification, and a copy-paste prompt.
---

When this skill is used:
1. Never emit a vague Codex task.
2. Break work into one narrow patch at a time.
3. Include:
   - title
   - goal
   - allowed files
   - forbidden files
   - exact prompt
   - verification commands
4. Avoid overlapping file scopes across tasks.
5. Prefer tasks that can be reviewed quickly.
